# 教程术语

本文件统一教程与维护文档使用的 Starsector 领域对象和机制用词。

## 使用规则

- 首次完整讲解必须定义实际概念，对初学者先说明对象和行为，再按需要引入术语。
- 非游戏常识的名称 (MOD ID、前缀、工具、原版内部 ID、社区俗称) 在首次出现处说明它是什么、从哪里来。玩家普遍熟悉的游戏用语，如 DPS、OP，直接使用。
- 原版舰船、武器、船插、战术系统等对象的中文名，以官方中文翻译为准，不自行翻译。
- 后续术语服务当前操作或机制，已有技术基础的讲解保持名称与对象准确对应。
- 词语按语义和上下文选择，抽象概括对应具体对象、条件或动作。
- 同名字段说明所属对象，流程直接说明实际成员、关系与调用时机。
- API、类、方法、字段、路径、ID、日志和界面原文必须保持原字符与大小写。

## MOD 与依赖

### MOD

- **原文**：`MOD / mod`。
- **统一写法**：MOD，文件与 ID 保持原大小写。

### 硬依赖 Hard Dependency

- **原文**：`hard dependency`。
- **统一写法**：硬依赖。

### 可选依赖 Optional Dependency

- **原文**：`optional dependency`。
- **统一写法**：软依赖 / 可选依赖。
