# 音频资源与播放

本章技术基线：Starsector `0.98a-RC8` 与 Java 17。

声音让玩家能够在画面之外辨认正在发生的事，也参与军备和场景的风格。本章介绍游戏音频的制作与接入，处理素材怎样成为可播放资源，以及这些资源怎样在合适的场合出现、持续和结束。

一段音频能否用于当前设计，同时取决于资源本身和播放方式。声道影响空间表现，循环接缝影响持续听感，触发时机又决定它是否与动作对应。掌握这些关系以后，您可以为已有内容安排自己的声音，也能把听感问题追到素材、配置或具体调用的位置。

**音频的效果要放在实际使用场景中判断。** 循环声会反复出现，战斗中又有多种声音同时播放，单独试听满意的素材仍需要结合这份环境调整。本章沿用已经完成的游戏对象，让资源选择和播放参数都有具体用途，逐渐形成一套可以持续扩充的声音配置。
