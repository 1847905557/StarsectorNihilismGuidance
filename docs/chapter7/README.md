# 全局服务

本章技术基线：Starsector `0.98.5a-RC3` 与 Java 17。

代码进入游戏以后，还需要在合适的时机取得它要操作的对象。本章介绍游戏提供的全局服务及其使用条件，使功能能够访问当前环境中的资源与状态，并把实际运行过程记录下来。

这些入口看起来都很容易调用，返回的对象却各有自己的归属。一份状态可能属于整个进程，也可能属于当前存档或本场战斗；加载另一份生涯、进入下一场战斗以后，所需对象也随之改变。**方法能取得引用，只是使用服务的一个条件。** 对象何时建立、由谁保存以及何时结束，决定了代码能够怎样使用它。

理解这种关系，就能为初始化、参数读取和运行中的反馈安排适当位置，也能解释某段代码为何在一个阶段有效、换个阶段就失败。本章会将调用环境与结果联系起来，给后面的开发建立清楚的访问入口；遇到问题时，日志中的对象与阶段也能提供具体的追查依据。
