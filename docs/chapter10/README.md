# 生涯世界与基础服务

本章技术基线：Starsector `0.98.5a-RC3` 与 Java 17。

生涯功能面对的是一份持续存在、又不断变化的世界。玩家抵达新的地点，势力关系发生变化，实体也有自己的位置和状态。本章介绍这份世界的基础对象与访问方式，使代码能够在当前存档中找到目标，并读取或改变它的实际状态。

世界中的对象有各自的范围与联系。地点容纳其中的实体，势力提供归属和关系，时间记录又影响访问与状态判断。配置定义了最初的内容，游玩过程继续改变它们。开发功能时，需要分清当前操作的是哪份对象，以及修改怎样进入这份生涯。

**稳定的身份与清楚的归属，是后续生涯制作的重要基础。** 已经生成的对象可以由其他功能继续查询和使用，保存读档以后也应当接回正确的世界状态。本章通过实际移动与状态变化说明这些关系，让今后的功能能够明确地回答：目标在哪里，当前是什么状态，这次操作又改变了什么。
