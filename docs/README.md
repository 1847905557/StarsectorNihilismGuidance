# 虚无主义教程 (Nihilism Guidance)

*本节预期阅读时间：\~3 分钟。*

*本节预期操作时间：\~0 分钟。*

## 前言

您好。

**这是一份支持远行星号 0.98a-RC8 (Starsector 0.98a-RC8) 的 MOD 教程**，旨在帮助制作一个基本的远行星号 MOD。

相信很多玩家在经历了或浅或深的游玩之后，抱着各种各样的心态希望创作出一些属于自己的内容。**无论是打算在远行星号社区创造一段令人尊敬的历史，亦或是有大大小小的愿望想要达成，哪怕只是想做一艘[天下无敌的舰船](https://www.fossic.org/thread-1562-1-1.html) 放烟花，您在初学者阶段都会需要一份教程来助您入门**。

**如果您觉得本教程太长了，您可以只看黑色加粗的精简摘要，其它部分稍后再作了解**。

::: details 好像有哪里出了问题？

如果您在阅读过程中感觉到自己被开了地图炮，或产生了类似的感觉，那么请您不要太认为自己的感受能代表其它人或群体的感受。如果可以的话，请您认为，编者并没有开地图炮，任何令您感到不适的语句都是专为攻击您一个人而写的。编者之前的所有文字亦是如此，包括仍存的和不复存在的。

:::

## 我需要什么？

**制作 MOD 几乎没有任何门槛**，您在掌握基本技巧之后完全可以自定义您的附加内容。

::: tip 技能要求？

**贴图**：在最坏的情况下，您也可以用原版裁剪拼接进行替代。只要不随意挪用其它 MOD 贴图或版权素材，就不违反任何法律、规定或用户协议。

**代码**：您几乎不会在这个初级阶段接触到灵活的代码，只需要复制黏贴原版的开放代码或本教程提供的代码即可。或者您也可以求助于 AI，编者推荐至少使用 GPT-6 Astra 水准 (勉强及格) 的 AI 辅助编写。

**音频**：您可以在网络公开素材库寻找音频，或直接使用原版音频。

**写作**：您只需要最基本的文字描述能力，即可撰写您自己看得过去的文本。

**英文水准**：您只需要熟悉使用[百度翻译](https://fanyi.baidu.com/) 即可。

**游戏水准**：制作 MOD 这个行为本身并不要求多高的游戏水准。即使您想要做一个优秀的作品而无法确定自己是否有能力驾驭可玩性，您也可以先尝试后更新修正，毕竟您现在看到的大多数老牌 MOD 都已经更新了数年之久，而它们一开始未必像现在这样优秀。

**设计水准**：抛开那些美化的修饰吧。设计的本质，就是在让玩家没发现自己在被 "教着玩游戏" 的前提下，成功地教玩家玩游戏。简单朴素一些的 MOD 也是可能被玩家接受的。

:::

虽然在技能方面几乎没有要求，但在心态上是有的。

::: tip 心态要求？

**您最不需要的是因 "一时脑热" 而催生的盲目热情或过度自信**。在创作的过程中，人容易产生自己 "无所不能" 的错觉，在 AI 辅助的情况下更是如此。请您注意调节心态。

**您最需要的是 "知道自己做出来的东西到底是什么" 的判断力**。就算往极端来说，您做了一个设计上非常糟糕的奇怪舰船或奇怪武器，那么只要您知道并承认它是这样的东西，那么这个做法就可以接受 —— 否则这不利于您的水平提升，也不利于您与其他人交流时的名望。

:::

## 制作需要多久？

**即使您此前完全没有基础与概念，制作一个具备上述一切内容的 MOD 也往往只需要 2 天**。制作 MOD 本身不是一件难事，普通玩家眼中的 "大佬" 其实非常好当。

本指南按进度组织章节：

Chapter 1–3 处理舰船、战机、武器、战术系统、船插等基础数据内容。您应该能迅速上手，并达成上述的 2 天目标。

Chapter 4–5 继续处理装配、战役、模块船、自定义实体、文本文件。您可能会在这里多花些时间，但 1 周也基本足够。

但在进入 Chapter 6 前，您需要理解基本 Java 语法，而那之后，大概就是**地狱**。

最后的几个阶段将用于介绍社区最为流行的前置与部分 MOD 的适配。

**一个真正精工细造的 MOD 往往需要至少 1 年 (考虑到您还有生活与其它事情去做) 来完善**。特别提到这一点是因为，编者见过太多急于求成但欲速则不达的作者了。

## 准备开始

除了上述信息之外，您还会至少需要 2 个工具。

- `sf-ship-ed`([点此下载](https://www.fossic.org/thread-1605-1-1.html)，远行星号主流的舰船编辑器)；
- `VS Code`([官网](https://code.visualstudio.com/)，一种主流的文本编辑器，需要在它的内部安装 `Rainbow CSV` 插件)。

这就够了，我们可以开始了。

## 交流讨论？

也许您会认为与他人沟通想法可以提供灵感，应该尽快寻找组织，**但编者认为未必**。

**请仔细想想，如果您只是一个连本教程都没有看完的新人，没有制作经验，甚至不清楚最基本的制作流程，那您可以交流讨论什么**？讨论本身就是意见的碰撞，若是您还没有形成属于自己的体验和理解，那就很难用适合创作的方式表达出您的意见且可能很难理解其他人的意见。**所以在与他人分享您的灵感之前，请至少学习本教程的前 2 章内容**。

其次，在交流讨论的过程中，难免会在自我展示的时候受到或善意或无意或捧杀的称赞。**如果您的内心不够坚定、判断力不足，那您可能会这种吹嘘和追捧之中迷失**，进而失去对质量的追求，在他人 "大佬" 的称呼中迷失各类认识。

更有甚者，**毕竟制作 MOD 本身是高度主观化、意见化的过程，技术交流方面的价值往往只会随着群内讨论内容日益低级而降低**。
