# 准备 OGG 音频资源

本节准备能够被 Starsector 读取的 Ogg Vorbis 音频文件，并把文件放到 MOD 的声音目录。完成后，文件可以在外部播放器中检查，再由 [C5-S2] 注册到 `sounds.json`。

*本节预期阅读时间：约 6 分钟。*

*本节预期操作时间：约 10 分钟。*

## 学习目标

完成后，您将能够：

- 将音频导出为符合游戏要求的 Ogg Vorbis 文件；
- 按声音 ID 命名文件并放入 `sounds/`；
- 检查声道、采样率、循环接缝和许可证记录。

## 前置知识

- [C1-S1] 的 MOD 目录和 UTF-8 无 BOM 规则；
- 能够使用音频编辑器导出 Ogg Vorbis；
- 能够检查文件属性和播放结果。

## 创建声音目录

在 MOD 根目录创建 `sounds/`，并把音频文件直接放在其中或其子目录。文件名使用 `GearIn_<subject>.ogg`，后续 `sounds.json` 与代码都使用同一个 ID。

本节使用以下文件：

### 本节音频文件速查表

| 文件 | 用途 | 声道 |
| --- | --- | --- |
| `sounds/GearIn_weapon_fire.ogg` | 武器开火音效 | stereo |
| `sounds/GearIn_system_loop.ogg` | 战术系统循环音效 | mono |
| `sounds/GearIn_market_theme.ogg` | 市场音乐 | stereo |

## 导出音频

将普通音效和音乐导出为 Ogg Vorbis。采样率使用 44100 Hz 或 48000 Hz；位置音效必须使用 mono，UI 音效和音乐使用 stereo。循环文件的首尾必须在波形和响度上连续，避免播放时出现明显跳变。

文件路径只允许使用 MOD 根目录相对路径。文件名大小写必须与后续 ID 和 JSON 路径一致。

## 记录许可证

为每个外部素材记录来源、许可证和修改方式。记录文件可以放在项目文档目录。`sounds/` 是原版的音频摆放惯例，游戏按 `sounds.json` 的 `file` 与 `source` 路径原样加载，并不限于该目录。

## 在播放器中检查文件

逐个打开三个文件，确认播放器识别为 Ogg Vorbis，声音内容正确，位置音效为单声道，UI 音效和音乐为双声道。完整播放循环文件，确认首尾没有明显接缝，并检查路径中没有拼写错误。

## 验证方案

前置数据：本节的三个 OGG 文件已导出并放入 `sounds/`，用于播放核对的外部播放器已安装。

1. 在文件管理器中确认三个 OGG 文件位于 `sounds/`。
2. 在外部播放器中播放每个文件。
3. 查看格式和声道属性。
4. 重复播放循环文件并观察接缝。
5. 保存许可证记录，随后进入 [C5-S2] 注册声音。

预期结果：

- 三个文件都能正常播放；
- 路径稳定；
- 循环文件连续；
- 每个文件都有可追溯的许可证记录。

## 故障分析

- **播放器无法识别文件**：文件扩展名与实际编码不一致。
    - **解决方案**：重新导出为 Ogg Vorbis，并确认文件没有被截断。

- **位置音效出现空间异常**：文件为 stereo。
    - **解决方案**：将位置音效重新导出为 mono。

- **循环出现明显断点**：首尾波形或响度不连续。
    - **解决方案**：裁剪首尾并在零交叉处重新导出。

- **游戏找不到文件**：路径或大小写与 `sounds.json` 不一致。
    - **解决方案**：按 MOD 根目录相对路径修正文件名。

## 总结

先在 `sounds/` 中准备并检查 OGG 文件，再在 [C5-S2] 写入声音定义。文件名、声道和路径在这一步确定，后续页面只引用这些稳定的声音 ID。

## 建议参考项

- `data/config/sounds.json`：原版声音注册表，本节文件在注册环节的格式蓝本。
