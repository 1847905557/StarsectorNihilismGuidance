# 生涯脚本与情报事件

本章技术基线：Starsector `0.98a-RC8`，Java 17。

生涯功能经常需要在一次创建或交互之后继续工作：等待时间、响应世界变化，或者将持续活动的状态告诉玩家。本章介绍这些运行入口，说明自己的逻辑怎样加入生涯，又怎样在条件满足以后更新或结束。

持续推进与事件响应有不同的调用方式，状态显示也有自己的登记和更新过程。将它们用于同一个功能时，需要明确由谁保存进度、哪项条件触发操作，以及玩家从哪里取得结果。**登记方式还决定这份功能怎样经过保存与读档。** 这些关系共同形成它在生涯中的实际寿命。

本章把运行、保存和显示联系到具体活动中，处理各自的对象范围与结束条件。以后制作限时效果、动态交互或长期情报时，可以根据功能需要选择入口，让活动状态继续推进，也让相关登记在结束后得到对应处理。
