# 文件读取与写入

本章技术基线：Starsector `0.98a-RC8` 与 Java 17；前置知识：MOD 目录、Global 服务、生命周期和 JSON/CSV 基础。

此前的许多数据放在游戏约定的路径，由对应系统加载。本章转向代码主动使用的文件：内容由谁读取，字段怎样解释，修改又保存到哪里，都需要由调用方安排。这让说明文字和配置可以随资源独立调整，也让运行中产生的记录有了保存与读回的入口。

**选择读取方式，也是在确定这份数据由谁提供。** 自有配置可以限定来源，公共表可以接纳其他 MOD 的新增与覆盖；同名内容如何处理，则取决于具体的合并约定。文件格式提供结构，读取入口决定来源，代码赋予字段实际用途，这些关系共同决定最终取得的内容。

发布的资源与用户的运行数据各有保存位置和使用时机。跨生涯报告需要在再次启动后读回，外置文字需要在显示前填入动态内容，数据格式变化也需要继续解释已有记录。本章围绕这些实际用途组织读写，使文件内容能够进入代码，并在需要时重新保存。
