# 无需入门的代码修改

本章技术基线：Starsector `0.98.5a-RC3` 与 Java 17。

上一章的内容全部写在数据文件里，而数据文件只能给出固定的数值。只在激活期间生效的强化、命中后附加的伤害、随船体级别变化的增益，都需要代码来实现。

本章不要求 Java 基础，也不教授 Java。但天无绝人之路，原版的战斗效果大多是几十行的短脚本，彼此结构相近。所以我们可以复制一份原版脚本，逐行推测它的作用，改写与设计有关的部分，再进游戏核对结果。

**看不懂的写法可以照搬，但您改动的每一行，都必须清楚它在做什么。** 否则一次报错就足以让您无从查起。系统学习 Java 是第六章以后的事。
