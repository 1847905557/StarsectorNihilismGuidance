# 战斗运行时

本章技术基线：Starsector `0.98.5a-RC3` 与 Java 17。

到前七章为止，写下的东西大多用在生涯或者装配界面里：入口类在启动时跑一次，设置读一次就用到底，船插的数值在装配界面被算出来、被玩家看到。这些都发生在战斗之外。

战斗是另一套运行环境。它有自己的对象表，一场战斗开始时把舰船、武器、弹体全部建出来，结束时全部丢掉，下一场重新来过。同一个船插在这里拿到的是一份只在战斗中存在若干分钟的副本，与玩家舰队里那艘船不是同一个对象。

所以在战斗里写东西，第一件事是想清楚它挂在什么东西上。挂在一场战斗上，范围覆盖全场、随战斗一起消失；挂在一艘船上，只作用于这一艘、跟着这艘船被摧毁；挂在一门炮上，只作用于这一门，这艘船上其他武器都不在其中。这三种位置能保存的状态、能取到的对象、什么时候失效，全都不同。**挂错一层，第一艘船上好好的，第二艘就开始出怪事**，而且往往没有报错。

本章的五节各自对应一种挂载位置，彼此独立，但都在同一场测试战役里观察。按顺序读，前面几节建立的战场会一直用下去。
