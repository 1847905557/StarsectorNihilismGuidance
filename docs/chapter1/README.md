# 基础及舰船相关

本章技术基线：Starsector `0.98.5a-RC3`。

本章要做的事，占了绝大多数 MOD 的绝大部分内容。舰船与武器是玩家每一场战斗都会亲手摸到的东西，一个 MOD 给人的第一印象几乎全由它们决定。代码能做的事情固然更多，但在这一层站不稳的设计，后面写多少代码都只会把它的问题放大。

本章的贴图都很粗糙。一艘船真正开进战场之前，没有人知道它值不值得一张精美的贴图，包括它的作者。先让它能动、能打、能被您亲自驾驶，再决定它配得上多少心血。

**编者对本章只有一个要求：为您做的每一样东西找到存在的理由。** 原版的舰船已经足够多。只靠数值略高来立足的船，谁都做得出来，也不会有人记得。
