# 常用依赖库

本章技术基线：Starsector `0.98.5a-RC3` 与 Java 17；依赖基线：LazyLib `3.0.0`、GraphicsLib `1.12.1`、MagicLib `1.5.6`。

社区依赖库把许多 MOD 反复需要的计算和功能整理成了公开入口。使用这些入口，可以把精力更多地放在当前效果与内容上：让几何计算服务于导弹制导，让光照和纹理表现舰船表面，也让生涯事件复用已有的生成与结算流程。本章以 LazyLib、GraphicsLib 和 MagicLib 为基础，讲解这些功能怎样进入自己的 MOD。

接入以后，有些功能由数据直接登记，有些则需要 Java 在适当回调中创建和提交对象。库负责的工作随入口而变，使用方仍要明确参数含义、对象归属和结束条件。**调用关系与资源关系同样重要。** 配置被读取后，还要在实际运行中使用正确的对象类型、满足相应的生成条件，才能产生预期的画面或任务结果。

本章的示例把这些关系放到具体成果中展开，既说明入口怎样使用，也说明它适合解决什么问题。现成工具提供了可复用的实现，制导如何选择目标、光效怎样保留轮廓、赏金透露多少位置情报，仍然属于当前作品的设计。理解库已经承担的工作，才能据此决定自己的代码与数据还要完成什么。
