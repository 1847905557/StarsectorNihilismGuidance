# 战斗内容扩展

本章技术基线：Starsector `0.98.5a-RC3` 与 Java 17。

第二章按没有 Java 基础的读者讲解军备效果，许多地方直接采用现成结构，说明也集中在当时需要修改的位置。现在已经具备了阅读代码和使用战斗 API 的基础，可以继续展开那些省略的部分。**本章深入讲解已有制作方式背后的接口、调用条件与实现机制。**

此前几行代码能够完成的效果，实际由游戏在特定阶段执行。同一个效果类会收到哪些对象，字段能保存什么状态，数据设置与脚本返回值又怎样共同决定结果，都需要结合具体调用理解。这些细节解释了现成结构为什么这样写，也决定了进一步修改时哪些做法能够成立。

本章继续使用熟悉的军备对象，把相关方法与实际表现对应起来。您可以据此理解已有示例中保留的结构，选用此前未展开的接口，并判断功能没有生效时应当核对哪项条件。需要制作更复杂的效果时，也就有了可以继续查阅和扩展的技术依据。
