# 势力与生涯星系

本章技术基线：Starsector `0.98a-RC8` 与 Java 17。

为一组军备设计所属势力，意味着它们开始具有共同的来历，也开始参与玩家的生涯。本章介绍势力与初始世界的基础制作：让齿轮工业拥有可辨认的身份和军备风格，并在星区中提供玩家能够抵达、交互的地点。

这些内容需要作为一个整体安排。势力怎样组织自己的军备，会影响玩家遇到的舰队；所属地点和初始关系，则决定玩家从哪里接触它、以怎样的态度与它往来。理解这些联系，就能把单独制作的内容纳入同一个世界，也能判断一项设定究竟落实到了哪些游戏表现上。

**势力的特色要在玩家反复接触的细节中成立。** 本章会建立这些基础联系，给后续更深入的生涯功能提供明确的归属。
