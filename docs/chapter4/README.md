# 战役与无代码对象

本章技术基线：Starsector `0.98a-RC8` 与 Java 17。

制作内容逐渐增多以后，还需要为它们安排合适的配置与使用场景。本章围绕游戏已经提供的数据结构扩展设计，既让军备有可以反复测试、展示的场合，也让外观和生涯地点能够使用自己的定义。

装配把一艘船的具体用途落实到装备选择上，通用类型与风格则使多处内容可以共享一套表现。理解这些配置怎样被游戏引用，就能将已经完成的设计用于不同场景，也能在组合新对象时分清哪部分属于共用定义、哪部分属于当前实例。这些关系是继续扩充 MOD 时经常需要处理的内容。

本章仍以文件制作和现成模板为主要手段。**游戏已有的配置能力足以支持相当多的设计变化**，值得先理解它们实际控制的范围。测试时也会分别确认加载、部署和显示：同一份设计在不同入口被使用，结果应当与您安排的配置相符。
