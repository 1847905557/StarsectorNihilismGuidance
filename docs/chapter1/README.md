# 基础及舰船相关

本章技术基线：Starsector `0.98.5a-RC3`。

许多制作念头都起于游玩中的一个具体想法：某艘船的槽位若换一种安排，某种火力若配上不同的代价，驾驶起来会怎样？本章从这些熟悉的游戏经验出发，介绍基础军备的制作，让自己的设计成为能够加载、装配并投入战斗的内容。

一件军备的外观、性能和说明分别保存在不同文件中，游戏通过标识与路径把它们联系起来。理解这种关系，您就能判断一个修改应当写在哪里，画面或数值出了问题又该从哪里追查。我们会使用原版素材与相近设计作为起点，逐渐建立从文件内容理解游戏表现的习惯。

**编者认为，基础制作最值得花心思的地方是设计的取舍。** 一项长处怎样影响装配选择，又需要付出什么代价，往往比单纯提高数值更能决定一艘船的趣味。本章的制作流程也围绕这一点展开：文件提供实现手段，亲自驾驶则让您确认自己的设想究竟产生了怎样的结果。
