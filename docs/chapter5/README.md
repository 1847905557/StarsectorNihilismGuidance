# 音频资源与播放

本章技术基线：Starsector `0.98.5a-RC3` 与 Java 17。

---

走到这里，您的舰船或许已经换上了专属贴图、武器特效与外观色系，但只要进场开火、开启战术系统或推满引擎，发出来的多半还是原版武器音甚至默认欧米伽引擎声。这一章把整套静态听觉资产一并补齐。

## 声音只在战场混响里作数，资源有限时的替换优先级

准备音效最容易犯的错误，是在桌面播放器里循环试听几秒就以为万事大吉。**音频的真实效果只能在数十门炮火混响的战场与长时间游玩中评判**。独立试听时觉得饱满厚重的一声开火，放进战列线齐射里可能完全被背景噪音盖掉；而在安静房间里听着挺顺耳的高频循环音，真挂在系统上每隔几秒响一次，打完半小时战斗往往就会令人心生烦躁。

同时从资源制备一开始就要分清格式口径：**战场定位音效必须使用单声道，只有不需要空间方位的界面交互音才用立体声**，因为游戏要凭单声道文件按镜头位置现场计算左右声道衰减，自带双声道的立体声反而会让战区声音定位彻底散掉。如果个人不具备专业混音能力或找不到成套高质量原声素材，**切忌硬塞进音量刺耳、底噪明显或来源五花八门的拼凑录音，应当先用原版优质素材垫实整套音频基线，再把有限精力集中优先替换最具辨识度的主力武器开火声与势力主题音乐**，每换掉一个都编进多舰齐射战局里听一轮再留用。

## 尊重玩家已有的战况直觉

另一处更需要克制的地方，在于不要把原版所有基础提示音全部推倒重换。护盾受击、幅能排散、系统过载与舰体殉爆的声音，对老玩家而言早已成为无需看字就能直接判断战场态势的条件反射。

**除非您的系统具有全新的专属提示语义，否则核心战况反馈音最好沿用或贴近原版听感**，让玩家凭听觉直觉立刻知道对面是否过载，远比强迫对方重新记忆一套陌生音色更体面。本章依然不碰代码，在战斗运行时按条件主动播放或调控循环音，留到第七章之后再用程序接口接手。
