# 人物与技能

本章技术基线：Starsector `0.98a-RC8`，Java 17。

人物可以成为生涯中可反复接触的角色，也可以通过职务和技能影响游戏运行。本章介绍人物的创建、关联与效果接入，使自定义人物能够被后续功能找到，在界面中出现，并承担实际的游戏角色。

人物资料、角色关系和技能状态分别有自己的保存位置。姓名与头像用于辨认，承担的角色决定技能作用于哪些对象，等级和效果定义再决定实际收益。**技能能否生效，要沿人物与作用对象的关系判断。** 这也使同一套人物接口能够支持不同用途。

本章既处理固定人物的持续身份，也说明人物数值怎样进入当前角色。保存、读档和重新应用以后，资料与效果还需要继续对应原来的对象。掌握这些关系，可以为任务准备稳定人物，为自己的舰队或市场配置角色，也可以进一步制作适用范围明确的技能。
