# 非强制性依赖

本章技术基线：Starsector `0.98a-RC8`（只描述当前基线）。可选前置：LunaLib 2.0.3、Nexerelin 0.11.3x —— 均为非强制性依赖，缺失时照常启动（各节降级路径可验证）。

本章处理一个问题：非强制性依赖（可选/软依赖）缺席时照常启动，在场时把对应功能接进来。第一节建立通用做法 —— 代码型软依赖用 `isModEnabled` 判断启用状态、把引用收敛进适配器（调用隔离），数据型软依赖按约定位置放配置文件（类存在性检测属进阶手段，默认不需要）；后两节分别把它用到 Nexerelin 的势力接入与 LunaLib 设置链的完整实例。完成后，您的 MOD 在缺少这些依赖时依然可用，装上后自动获得对应功能。
