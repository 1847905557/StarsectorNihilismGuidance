# 生涯舰队与舰队成员

本章技术基线：Starsector `0.98.5a-RC3` 与 Java 17。

本章给 Nipher 添一支巡逻队。它规模不大，也不去追人，但有旗舰和指挥官，受了重伤会返航修理，装配一看就是齿轮工业的手笔。

舰队是生涯里唯一会自己动的东西。星系不动，市场不动，玩家不动的时候世界就不变；舰队会跑、会打、会被打散、会在几十天后重新出现。所以给一个势力加内容，做几支舰队比做十个地点都有效。

麻烦的从来不是生成。`FleetFactoryV3` 一行调用就能按势力抽出船来，难的是之后：它归谁管、数量由谁维持、任务队列空了怎么办、被打残了怎么回家、装配该不该和别的船一样。这些问题在生成那一刻全都还不存在，等玩家遇上才会暴露。

本章把舰队拆成两层写：舰队本身管方向与任务，成员管这条船的装配与状态。两层各有各的对象，混着改会到处是找不到原因的怪现象。

一支舰队用不着多强，玩家两次路过能认出是同一批人，就够了。
