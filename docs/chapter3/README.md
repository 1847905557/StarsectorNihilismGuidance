# 势力与生涯星系

本章技术基线：Starsector `0.98.5a-RC3` 与 Java 17。

到上一章为止，齿轮工业的舰船和武器都能在模拟战里开火，却还不属于星区里的任何人。本章给它们一个归属：一个有名字、有舰队、有据点的势力。

并不是每个 MOD 都需要这一章。只想往原版势力里添几艘船的舰船包，让原版势力学会这些船就够了。**当您的内容需要一个自己的来历时，才需要自己的势力。** 齿轮工业的船都是从原版蓝图改出来的，改它们的人总得有个名字。

本章做的是开局那一刻的世界：势力掌握哪些军备、和谁交好、据点在哪。开局之后，舰队怎样巡逻、市场怎样交易、势力之间怎样开战，都由游戏接手。**您负责布好开局，之后的事交给游戏。** 所以编者建议您动手前先想清楚它在开局时应该是什么样子，开局之后再改，往往就得开新档测试了。

**势力的特色要在玩家反复接触的细节中成立。** 玩家多半不会读完您写的设定，他们在星图上遇见、停靠、交火，几次之后就有了印象。此后的市场、任务与情报都会建立在这个势力上，您会反复修改它很久；第一版不必完美，能让人认出来就够了。
