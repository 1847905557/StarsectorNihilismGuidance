# CSS Guidelines

本文件规定教程站与开发模式页面编辑器的样式维护。文字排版见 `.zcode/text-guidelines.md`，交互与编辑状态见 `.zcode/frontend-guidelines.md`。

## 展示归属

- 站点通用样式由 `docs/.vuepress/styles/index.scss` 维护，开发编辑器样式由所属客户端展示维护。
- 样式围绕实际页面、工具栏、状态提示、代码块、容器和表格组织。
- 通用内容与编辑态内容使用各自选择器范围，共同展示复用同一基础规则。
- 修改选择器时必须核对模板、渲染函数、动态 class 和编辑节点绑定。

## 布局与交互

- 站点主题负责页面框架，编辑器负责浮动工具栏、编辑正文和内部控件布局。
- 操作组按可用宽度排列，窄窗口通过换行与滚动保持控件可用。
- 表格表头的换行要求归站点规则，代码正文、高亮行和行号的排布归所属编辑节点。
- 编辑器样式保留输入、焦点、文本选择、图片选择和表格操作行为。
- 控件、容器和状态提示有明确展示身份，间距与对齐由布局承担。

## 主题与维护

- 颜色、字体和代码块展示优先消费 VuePress 主题变量。
- 常态、悬停、选中、禁用、错误和编辑焦点分别对应所属状态。
- 局部尺寸服务实际控件与展示需求，复用参数有共同消费者。
- 样式调整在明暗主题与宽窄窗口核对布局、换行、滚动和焦点呈现。
