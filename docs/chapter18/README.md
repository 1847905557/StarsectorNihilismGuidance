# 常用依赖库

本章技术基线：Starsector `0.98a-RC8` 与 Java 17；依赖基线：LazyLib `3.0.0`、GraphicsLib `1.12.1`、MagicLib `1.5.6`。

前面的游戏对象和回调已经可以组合成自己的功能，这一章继续接入社区工具库。LazyLib 用于几何、战场查询和公共数据，GraphicsLib 用于光照与表面纹理，MagicLib 用于尾迹、赏金、生涯布置和战斗显示。先建立依赖，再按当前效果调用已有入口；编者建议每次带着一个具体问题使用库，效果和调用关系都更容易看清。
