# 音频资源与播放

本章技术基线：Starsector `0.98.5a-RC3` 与 Java 17。

到这里为止，齿轮工业的船开火、开系统、加速时发出的都是原版的声音，或者干脆是欧米伽的引擎声。本章把它们换成齿轮工业自己的。

**音频的效果要放在实际使用场景中判断。** 战场上同时响着几十种声音，单独试听很满意的开火声，混进去可能就听不见了；在耳机里还算顺耳的循环声，在战场上每隔几秒就响一次，很快就会让人烦。所以编者建议您先借用原版素材把整套声音在游戏里配齐，再一个个换成自己的，每换一个都回到战场上听一遍。

本章仍然不需要写代码。在战斗中按条件播放声音、自己控制循环与音乐，留到第七章。
