# 生涯舰队与舰队成员

本章技术基线：Starsector `0.98.5a-RC3`，Java 17。

生涯中的舰队既是地图上行动的对象，也保存着每艘舰船的具体情况。本章介绍舰队和成员的创建、管理与修改，使代码能够安排一支舰队的组成和行动，也能处理其中某艘船在生涯中的状态。

舰队整体、成员与装配各自保存不同内容，又会共同影响当前结果。改装一艘船以后，成员数值需要按配置重建，整支舰队的汇总也要反映变化。理解这些联系，才能知道一次写入实际改变了哪一层，以及后续读取应当从哪里取得结果。

**生涯成员还承担着舰船跨战斗、跨读档的身份。** 本章将即时修改与后续整备、部署和保存联系起来，说明哪些状态会继续保留，哪些结果会被重新计算。以后需要生成任务舰队、发放舰船或调整既有成员时，就可以沿这些对象关系完成操作。
