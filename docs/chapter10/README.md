# 生涯世界与基础服务

本章技术基线：Starsector `0.98.5a-RC3` 与 Java 17。

前面几章改的都是既有的东西：船插挂在已有的舰船上，战术系统装进已有的船体，武器换掉原版的那几行。这一章第一次造出属于自己的世界：一个星系、一个市场、一个势力，以及玩家与它们之间发生过的事。

生涯层的对象留在存档里。关掉游戏再读回来，星系还在原来的位置，势力的关系还是上一次的样子，玩家三十个生涯天前到过哪里也还在。这些值不会自己消失，写进去就一直留着，直到有人把它清掉。

所以第一件要决定的是值存在哪一层。存档公共数据、实体或市场的 Memory、某支舰队的 Memory、脚本的字段，四种地方都在用，前三种进存档，脚本字段不进。挑错一层，值会在不该消失的时候消失，或者在本该消失之后一直留着。

建立与加载分开处理。开新档时建立世界，读档时只补上不该重复建立的东西。写错位置的表现很一致：新档一切正常，读档之后世界里多出第二个星系，或者势力关系回到初始值。

生涯层的对象大多是共享的：同一份装配被若干成员使用，同一个势力被整个星区引用。改这类对象之前先复制一份，或者改用会触发同步的增删方法，否则改一处，引用它的每一处一起变。本章的几节都会碰到。
