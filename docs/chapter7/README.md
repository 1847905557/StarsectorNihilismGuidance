# 全局服务

本章技术基线：Starsector `0.98.5a-RC3` 与 Java 17。

前六章做出来的东西，都是玩家能在屏幕上看到、能从装配界面读到、能在战斗里按出来的。本章做的东西全都看不见：入口类被叫了没有，参数从哪里读，音效进了哪条声道，报错写进了哪一行。做完之后游戏跟没装这个 MOD 时没有区别。

**这一步是所有后续内容的前提，也是最容易被跳过去的一步。** 一个 MOD 前期看不出问题，后期才炸，原因大多在这里：本该开新档才生效的东西写进了日常加载，本该进设置文件的数值硬编码在类里，本该读的日志一次也没打开过。这些东西在功能少的时候都不致命，等功能多了，改一处就得重测全部。

能配置的不要硬编码，该开新档的就老实要求开新档，出问题先读日志再动手。本章之后，这些都默认您已经会做，后面各章不会再提醒。
