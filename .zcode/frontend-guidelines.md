# Frontend Guidelines

本文件规定 `docs/.vuepress/` 中 Vue、TypeScript、VuePress 与 Markdown 插件的通用写法。项目装配与调用链见 `.zcode/overview.md`，样式见 `.zcode/css-guidelines.md`。

## 代码组织

- 配置入口负责装配，Markdown 插件负责 token 转换，开发模式插件负责文件请求，客户端负责编辑交互。
- TypeScript 通过类型和函数表达输入输出，外部输入在消费边界确认结构。
- 运行时依赖和类型依赖在文件顶部导入，同类能力沿用相同组织与命名。
- 内容转换保持独立，文件读写、进程调用和浏览器 DOM 操作归各自执行环境。
- 辅助函数有明确的复用或职责依据，同类处理优先复用现有实现。

## 页面发现与 Markdown

- 导航和章目录从真实章、节目录及页面 H1 读取标题，编号对应目录身份。
- Markdown 扩展按 token 类型和上下文处理内容，代码和已有链接保持各自语义。
- 章节引用消费站点 base 与实际目标页面，生成链接对应站点路由。
- 文件监听围绕目录、页面身份和标题变化触发刷新，watcher 与定时器纳入所属生命周期。

## 编辑状态与交接

- 编辑器在本地开发环境装配，页面路径、原始内容和源版本随本次编辑捕获。
- 编辑、保存、取消确认、热更新等待和错误状态由当前实例维护。
- 页面切换和组件卸载必须释放编辑器、事件监听、观察器和定时器。
- 提交传递页面路径、捕获版本和当前 HTML，写回成功后使用返回版本完成页面更新交接。
- 保存期间的输入控制、版本冲突和诊断交付明确反馈，失败后必须保留可继续处理的编辑内容。
- 代码语言、高亮行、容器、列表、链接、表格和图片通过所属编辑模型保留到恢复流程。

## 文件与恢复边界

- 编辑请求由所属中间件确认方法、目标路径、版本和请求内容。
- 写回目标必须位于实际 `docs/` 范围，图片对应现有页面资产。
- HTML 恢复直接消费 `tools/restore-markdown.mjs` 的正式函数，调用方交付诊断，所属写回流程完成文件操作。
- 写回维护文件备份、规范化文本、原子替换与新版本回执。
- 恢复结果与错误保留原始定位信息，页面编辑与命令检查复用相同内容规则。

## 测试与注释

- 编辑模型测试覆盖 DOM 到编辑内容的转换，插件测试覆盖路径、版本、恢复和写回结果。
- 测试断言公开结果与协议，临时文件和进程随所属测试释放。
- 交互变化沿实际页面验证输入、选择、确认、取消和保存结果。
- 注释说明外部契约、转换意图或顺序条件，公开函数说明对应实际输入、输出和失败语义。
