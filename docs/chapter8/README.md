# 战斗运行时

本章技术基线：Starsector `0.98.5a-RC3` 与 Java 17。

战斗中的自定义效果，需要与正在发生的过程共同运行。目标可能被摧毁，玩家可以暂停，伤害又会经过多项修饰才形成结果。本章介绍这套运行环境，让代码能够取得当前对象、参与对应操作，并安排自己的持续状态与显示。

这里关注的是效果怎样与游戏配合。一次事件提供本次的目标和结果，持续逻辑按照实际时间更新，多个数值来源则共同参与计算。理解这些关系，您就能判断一项设计应由哪个对象承担、在什么时机执行，以及结束后哪些内容需要解除。

**功能的计算结果与玩家见到的反馈需要一起成立。** 加成已经写入，并不说明显示使用了正确的对象；画面出现了特效，也仍要确认它对应哪次事件。本章将这些部分放在同一场战斗中观察，建立以后制作复杂效果时可以继续使用的运行方式。
