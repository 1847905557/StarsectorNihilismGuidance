# Java 工程化

本章技术基线：Starsector `0.98.5a-RC3` 与 Java 17。

**从本章开始，教程假定您已掌握基础 Java 知识。** 后面的讲解会直接使用类、接口和集合等概念，把重点放在游戏提供的对象与行为上。进入这部分制作之前，先将现有代码组织为可以独立构建、持续开发的工程。

一个工程需要明确源码的位置、编译所需的类型和最终交给游戏的产物。这些条件共同决定代码怎样从编辑器中的文本变成游戏实际加载的类；也决定换一台电脑或把工程交给他人时，构建过程能否继续成立。本章介绍这层关系，并将它落实到可保存、可重复执行的配置中。

构建工具的价值在于**让工程自身说明怎样构建**。依赖和目标版本有明确位置，产物也有确定的内容与去向，后续功能增加时就能沿用这些条件。至于工具提供的其他能力，按实际开发需要再选择即可；当前工程服务于 MOD 的编译、打包与加载。
