# 无需入门的代码修改

本章技术基线：Starsector `0.98a-RC8` 与 Java 17。

有些设计会随着战斗过程改变：强化只在激活期间生效，命中后才出现额外反馈，说明文字也需要跟随当前参数。这些行为需要代码参与。本章介绍怎样修改现成的效果代码，把基础军备扩展为能够响应游戏过程的内容。

这里将按没有 Java 基础的读者讲解。您可以沿用原版或示例已经提供的结构，理解其中与当前效果有关的部分，再调整自己的设计。**需要建立的认识是：数据怎样找到代码，游戏何时执行它，修改又怎样影响实际结果。** 熟悉这层关系，复制与修改才有明确的依据。

代码让可调整的范围扩大了，效果的取舍也因此更重要。同一个速度增量，对不同船体可能有完全不同的价值；短时强化的强度，还与持续时间和使用机会有关。我们将这些判断放回实际测试中，逐渐熟悉自己的修改意味着什么。

完整的 Java 学习仍需由您自行安排；从第六章开始，教程将以基础 Java 知识为前提继续讲解。
