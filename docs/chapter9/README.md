# 战斗内容扩展

本章技术基线：Starsector `0.98.5a-RC3` 与 Java 17。

第二章的东西能跑，靠的是把原版文件抄一份、改掉该改的几行。这种做法在需求简单时完全够用：一门炮能开火，一个系统能按下去，一条船插能改数值，游戏就认。

问题在于原版文件里那些没被抄过来的部分。船插的 S 插效果、与原版船插的互斥、作用于整支舰队而不是一艘船的加成；战术系统的自定义 AI、效果对模块的同步、待机时也要维持的被动；武器动画的帧图、转速、开火与停火的区别。这些都不在 "能用" 的范围内，玩家却会在装配界面里逐项比较，会看状态栏，会把舰船交给 AI，也会拿它跟原版的东西对着看。

**能用的效果和经得起比较的效果之间，隔的是这一层细节。** 本章不引入新玩法，只把第二章绕过去的地方补上。三节各自针对一类对象，做法互不相干，可以按需要挑着读。

前面教的是怎么让东西动起来，从这里开始教的是怎么让它动得对。
