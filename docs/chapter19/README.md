# 可选依赖与 Nexerelin

本章技术基线：Starsector `0.98a-RC8` 与 Java 17；可选依赖基线：Nexerelin `0.12.1e`、LunaLib `2.0.5`。

玩家采用的 MOD 组合会改变一份内容的运行环境。可选依赖接入需要为这些组合安排各自的行为：依赖启用时，内容参与对方提供的系统；依赖缺席时，基础功能按既定方式运行。本章用 Nexerelin 与 LunaLib 展开这种接入，说明编译依赖、类加载和实际调用之间的关系。

对 Nexerelin 而言，一个已经存在的势力还需要参与它的世界生成与生涯运行。配置提供资格、倾向和规模，运行中的市场与关系提供当前状态，事件再把实际结果交给自己的代码。**固定星区与随机星区采用不同的对象来源。** 兼容工作因此既要确认登记，也要理解对方何时取得对象、怎样作出决定。

可选设置则让玩家调整 MOD 的部分行为。面板保存值，使用方在自己的运行时机读取，才会产生画面或功能变化。无论接入生涯系统还是设置服务，本章都围绕已有内容与外部系统的配合展开，使扩展功能拥有明确的接入条件和使用范围。
