# Java 工程化

本章技术基线：Starsector `0.98.5a-RC3` 与 Java 17。

前五章的代码都放在 `data/` 里，由游戏在启动时自己编译。这样做不需要安装任何开发工具，但游戏自带的编译器只认一部分 Java 语法，写错了要等进了游戏才知道，编辑器也帮不上忙。代码少的时候，这些都还能忍。

本章把代码搬进一个真正的 Java 工程，由 JDK 编译、打包成 JAR，再交给游戏加载。

**从本章开始，教程假定您已掌握基础 Java 知识。** 类、接口、继承、集合、泛型，此后都直接使用，不再解释。还不熟悉的话，编者建议先找一本 Java 入门书补上，再回到这里。后面各章的难点在于游戏怎样组织它的对象，Java 语法反倒是最容易的部分。

工程搭好以后，它就是此后所有代码的地基。**构建配置是工程的一部分，应当写进文件，而不是留在某台电脑的编辑器设置里。** 一年后换了电脑，或者把工程交给别人，照着这几个文件就能原样构建出来。
