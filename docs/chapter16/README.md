# 酒吧事件与任务

本章技术基线：Starsector `0.98.5a-RC3`，Java 17。

玩家通过交互接触任务、作出选择，并收到相应结果。本章介绍生涯对话与任务的组织方式，让自己的功能具有可进入的界面，也能将一次会话中的决定接到后续生涯过程。

对话中的文字和选项呈现当前信息，实际结果则由对应功能保存。一次交互结束以后，邀请可能继续存在，已经接受的任务也可能仍在等待条件满足。**会话的结束与任务的结束各有自己的含义。** 区分这些状态，才能正确处理再次进入、继续推进和最终结算。

本章围绕这些联系展开实现：界面怎样接收选择，功能怎样处理结果，长期进度又怎样在离开会话后延续。掌握这套组织方式，可以把交易、检查或其他任务内容接入生涯，让玩家在不同阶段获得与当前状态对应的信息和行动入口。
