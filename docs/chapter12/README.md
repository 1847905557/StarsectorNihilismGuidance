# 市场与商品

本章技术基线：Starsector `0.98a-RC8`，Java 17。

玩家在生涯中取得和使用物资，背后涉及库存、交易规则与市场经济。本章介绍这部分对象和扩展入口，使自己的内容能够参与货物转移、市场交易与生产，并在相应界面提供实际结果。

这里需要区分数据定义与当前状态。一种商品具有共用规格，到了不同市场却有不同的供需和报价；货舱保存具体物品数量，产业声明的生产规模又采用经济档位。**对象与数量的含义明确，交易和生产代码才有正确的计算依据。** 本章会结合实际操作说明这些区别。

市场中的效果还会随着经济更新、功能状态和玩家行为重新计算。制作专用交易或生产内容时，需要把输入、处理条件与后续结果接到对应入口，再确认它们怎样相互影响。掌握这套关系以后，就能为 MOD 建立自己的经济内容，并理解它进入现有市场之后的行为。
